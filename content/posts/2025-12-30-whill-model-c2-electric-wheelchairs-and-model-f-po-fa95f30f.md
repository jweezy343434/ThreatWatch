**What Happened**
WHILL Model C2 electric wheelchairs and Model F power chairs contain critical cybersecurity vulnerabilities in their connected systems. These mobility devices use wireless connectivity and mobile applications for remote control and monitoring features. Security researchers identified weaknesses in the devices' communication protocols, authentication mechanisms, or software components that could allow unauthorized access to the wheelchair's control systems.

**Impact**
This vulnerability poses serious safety risks to users who depend on these mobility devices for daily transportation and independence. Malicious actors could potentially gain unauthorized control over wheelchair functions, including steering, speed, and braking systems, putting users at immediate physical risk. Beyond safety concerns, attackers might access personal data stored on connected devices or intercept communications between the wheelchair and companion mobile applications, compromising user privacy and location information.

**Actions**
Users should immediately check for and install any firmware updates provided by WHILL through official channels. Disable unnecessary wireless features and avoid connecting to unsecured networks when possible. Contact WHILL customer support to verify current security patch status and obtain guidance on safe operation procedures. Healthcare facilities and organizations managing fleets of these devices should conduct security assessments, implement network segmentation for connected wheelchairs, and establish incident response procedures. Monitor CISA advisories and WHILL communications for additional security updates and follow manufacturer recommendations for secure configuration of all connected features.
